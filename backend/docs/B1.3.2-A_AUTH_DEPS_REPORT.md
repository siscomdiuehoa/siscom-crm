## 2. Quy tắc biến (mặc định khi không khai báo)
| Biến | Mặc định | Ràng buộc |
|---|---|---|
| JWT_ACCESS_SECRET | (không có) | ≥ 32 byte UTF-8, không chứa `CHANGE_ME` |
| JWT_ACCESS_SECRET_PREV | (không có) | chỉ khi có khóa hiện tại; cùng ràng buộc; phải khác khóa hiện tại |
| ACCESS_TTL_SECONDS | 600 | số nguyên 60..3600 |
| REFRESH_IDLE_DAYS / REFRESH_ABS_DAYS | 7 / 30 | 1..30 / 1..90; idle ≤ abs |
| COOKIE_SECURE | true | `true`/`false`; production cấm `false` |
| AUTH_ALLOWED_ORIGINS | = CORS_ORIGINS | URL http(s) không đường dẫn, cấm `*` |
| TRUST_PROXY | false | `false`, `loopback` hoặc 1..5; cấm `true` (giả mạo IP vô hiệu throttle) |

Các giá trị đã chuẩn hoá trả về qua ConfigService: `ACCESS_TTL_SECONDS`, `REFRESH_IDLE_DAYS`, `REFRESH_ABS_DAYS` (number), `COOKIE_SECURE` (boolean), `AUTH_ALLOWED_ORIGIN_LIST` (mảng), `TRUST_PROXY`. Chưa có mã nào dùng các giá trị này (gói C).
