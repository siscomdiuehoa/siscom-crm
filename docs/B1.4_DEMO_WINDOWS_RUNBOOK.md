# Runbook demo/nghiệm thu SISCOM CRM trên Windows (PostgreSQL thật, database thử, Chrome)

Áp dụng: `main` sau PR #184 (B1.4: tách role S1, quyền V3 hai pool, Remember Me 90 ngày). Máy: Windows 11 của owner, PostgreSQL 18 dịch vụ `127.0.0.1:5432`, Node.js ≥ 22, Chrome.
Mục tiêu: dựng **một database thử mới** (`siscom_crm_test_YYYYMMDD_HHMMSS`) đúng kiến trúc bảo mật (3 role, 2 pool), chạy backend + giao diện trên máy, nghiệm thu bằng Chrome.

**Không dùng cho:** `siscom_crm_dev`, hai baseline đã khoá (`siscom_crm_restore_20261014_214105`, `siscom_crm_restore_20261015_214948`), production, Internet. Mọi script tự từ chối các tên này.

## 0. Ảnh hưởng tới máy chủ PostgreSQL (đọc trước)
- Tạo **1 database mới**. Không sửa/xoá database nào khác.
- Lần đầu chạy bước 4 sẽ tạo **2 role cấp cluster**: `siscom_migrator` (chủ sở hữu DB thử) và `siscom_auth` (pool xác thực). Mật khẩu sinh ngẫu nhiên 64 ký tự, lưu ở `%LOCALAPPDATA%\SISCOM-CRM\demo\roles-5432.secrets` (ngoài repo; chỉ tài khoản Windows của anh đọc được). Không ai cần gõ hay xem mật khẩu này.
- Cấp `SET ON PARAMETER app.actor_employee_id, app.priv_request_id` (toàn cluster) cho `siscom_app` (đã có từ B1.3) và `siscom_auth`.
- `REASSIGN OWNED` trong bước tách role đã được kiểm để **không đổi chủ sở hữu database khác** (C1): diễn tập trên cluster tạm có DB "canary" thuộc `siscom_app` — giữ nguyên chủ sở hữu và quyền CONNECT.
- Không đụng `.env` (chỉ đọc mật khẩu `siscom_app` trong `DATABASE_URL`).

## 1. Chuẩn bị (một lần)
```bat
cd /d D:\SISCOM-CRM
git checkout main
git pull --ff-only
cd backend
npm ci
npm run build
cd ..\frontend\siscom-crm-web
npm ci
set VITE_CRM_AUTH_ENABLED=true
set VITE_CRM_API_ENABLED=true
set VITE_CRM_API_BASE=/api/v1
npm run build
```
Kiểm: `backend\dist\main.js` và `frontend\siscom-crm-web\dist\index.html` tồn tại. `backend\.env` có `DATABASE_URL` trỏ `siscom_app@127.0.0.1:5432/siscom_crm_dev` (script chỉ đọc mật khẩu `siscom_app`, **không kết nối** `siscom_crm_dev`).

## 2. Tạo database thử
Mở thư mục `D:\SISCOM-CRM\backend\scripts\windows`, chạy:
```bat
create-test-db.bat
```
Nhập mật khẩu `postgres` khi được hỏi (không lưu). Ghi lại dòng **TÊN DATABASE THỬ** (dưới đây gọi là `<DB>`).

## 3. Migrate, danh mục, tài khoản (DB còn thuộc `siscom_app`)
```bat
auth-demo-stack.bat -Step migrate   -DatabaseName <DB>
auth-demo-stack.bat -Step seed      -DatabaseName <DB>
auth-demo-stack.bat -Step bootstrap -DatabaseName <DB>
```
- Mỗi bước hỏi gõ lại tên DB để xác nhận.
- `bootstrap` hỏi mật khẩu cho 5 tài khoản (sysadmin/admin/sale/kythuat/ketoan`@siscom.local`), ≥ 12 ký tự, **mật khẩu mới** (không dùng lại bộ demo cũ đã lộ). Chỉ chạy được **một lần** cho mỗi DB.
- **Thứ tự bắt buộc:** seed và bootstrap phải chạy **trước** bước 4 (sau khi tách role, `siscom_app` không còn quyền ghi danh mục/tài khoản — đúng thiết kế).

## 4. Tách role (khuyến nghị cho nghiệm thu bảo mật)
```bat
demo-split.bat -Step split -DatabaseName <DB>
```
Script làm lần lượt (dừng ngay nếu một bước lỗi): ROLE_SPLIT → AUTH_ROLE → APP_GRANTS_V3 ×2 → VERIFY (pool nghiệp vụ) → VERIFY_AUTH (pool xác thực).
Kết quả đúng:
```text
[DAT] VERIFY (pool nghiep vu siscom_app) PASS|73
[DAT] VERIFY_AUTH (pool xac thuc siscom_auth) PASS|33
```
Bất kỳ dòng `KHONG DAT` nào: dừng, chụp màn hình gửi lại.

Chạy lại bước này an toàn (idempotent). Kiểm lại quyền bất cứ lúc nào (chỉ đọc): `demo-split.bat -Step verify -DatabaseName <DB>`.

## 5. Chạy backend
```bat
auth-demo-stack.bat -Step start -DatabaseName <DB>
```
- DB đã tách: script tự đặt `AUTH_DATABASE_URL` (pool `siscom_auth`), in `AUTH_DATABASE_URL = siscom_auth`.
- Kiểm trong trình duyệt: `http://127.0.0.1:3000/api/v1/health/database` phải có `"authPool":"separate"`, `"leastPrivilege":true`, `"authLeastPrivilege":true`.
- Chế độ demo nội bộ: `NODE_ENV=development`, `COOKIE_SECURE=false` (http trên máy). **Không** mở ra Internet.
- Dừng: Ctrl-C trong cửa sổ đó.

## 6. Chạy giao diện
Cửa sổ dòng lệnh khác:
```bat
cd /d D:\SISCOM-CRM\frontend\siscom-crm-web
npm run preview
```
Mở Chrome: `http://127.0.0.1:4173`.

## 8. Khi có migration mới (sau khi đã tách role)
```bat
demo-split.bat -Step migrate -DatabaseName <DB>
```
Chạy `prisma migrate deploy` bằng `siscom_migrator`, rồi **tự chạy lại V3** và VERIFY (bảng mới nhận quyền SELECT mặc định cho `siscom_app`; VERIFY B1f bắt nếu quên). Không dùng `auth-demo-stack -Step migrate` cho DB đã tách (script từ chối).

## 9. Dọn dẹp / rollback
- Dừng backend (Ctrl-C) và `npm run preview` (Ctrl-C).
- Database thử chỉ phục vụ demo. Khi không cần, **anh tự** xoá bằng pgAdmin hoặc `psql -U postgres -c "DROP DATABASE <DB>;"` (Claude không chạy lệnh xoá).
- Gỡ quyền/role khi bỏ hẳn kiến trúc tách role trên máy (superuser, theo thứ tự, chỉ khi không còn DB thử nào dùng):
  `B1.3_S1_AUTH_ROLE_ROLLBACK.sql.txt` → `B1.3_S1_ROLE_SPLIT_ROLLBACK.sql.txt` (`backend\docs`, có hướng dẫn trong đầu file). Không bắt buộc cho demo.
- File mật khẩu role: `%LOCALAPPDATA%\SISCOM-CRM\demo\roles-5432.secrets` — xoá khi đã gỡ role.

## 10. Sự cố thường gặp
| Thông báo | Cách xử lý |
|---|---|
| `Khong thay file .env` | Chạy từ `D:\SISCOM-CRM` hoặc thêm `-EnvPath D:\SISCOM-CRM\backend\.env` |
| `Thieu dist\...` | Chạy lại mục 1 (`npm run build`) |
| `DB da tach role ... buoc seed/bootstrap khong dung o day` | Seed/bootstrap phải trước bước 4. Tạo DB thử mới, làm lại từ mục 2 |
| `Role siscom_migrator da ton tai nhung file mat khau chua co` | Role tạo từ máy khác/cách khác. Chạy lại không kèm `-NonInteractive` để nhập mật khẩu hiện tại, hoặc nhờ hỗ trợ đặt lại |
| `VERIFY ... KHONG DAT` | Dừng, gửi ảnh chụp. Không sửa tay quyền DB |
| Backend báo thiếu quyền / 500 khi đăng nhập có tích | DB vừa migrate mà chưa chạy lại V3: `demo-split.bat -Step migrate` hoặc `-Step split` |
| Đăng nhập có tích lỗi sau khi đổi giờ máy | Đồng bộ giờ Windows (máy ứng dụng và DB lệch > 5 phút bị DB chặn) |

## 11. Bằng chứng diễn tập (trước khi giao)
Diễn tập toàn bộ mục 2–7 trên cluster PostgreSQL **tạm cách ly** (`127.0.0.1:55432`, dữ liệu giả, chỉ có sẵn `siscom_app` + DB canary như máy owner) bằng chính các script này — `docs/evidence/b1.4_demo_windows_runbook_20261101/`.
